# Roles

- **Root/integrator** — owns scope, permissions, knowledge state, user communication, GitHub approval gates, and final verification.
- **Planner** — produces read-only architecture or high-impact trade-off decisions.
- **Implementation worker** — edits only explicitly assigned project files and returns validation evidence.
- **Independent reviewer** — performs a fresh read-only check against acceptance and privacy criteria.

No role may publish, delete content, install dependencies, or broaden the data boundary without explicit authority.
