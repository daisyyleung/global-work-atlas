# Extension guide index

## Purpose

Route readers to optional designs that are deliberately outside the included static runtime. This folder contains no credentials, deployment state, or claim that an extension is implemented.

## Read when

Read the relevant guide before proposing a change to the account-free, local-first architecture.

## Inventory and authority

- `optional-google-oauth.md` — current framework-neutral setup and security requirements for a future server-backed Google sign-in extension.

The implemented runtime boundary remains authoritative in `../00_system/architecture.md`, `../PRIVACY.md`, and `../SECURITY.md`.
