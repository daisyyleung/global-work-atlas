# Decision

Create the public edition from an empty root with newly authored code, copy, sample data, and vector artwork. Do not copy private records, assets, configuration, artifacts, deployment state, or history.

## Rationale

Exclusion by construction is stronger than attempting to redact an account-connected application after copying it.

## Revisit when

Do not weaken this boundary for convenience. Any proposed exception requires an exact artefact inventory, rights review, privacy review, and explicit approval before transfer.
