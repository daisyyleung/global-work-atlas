# Glossary

- **Workspace** — one versioned collection of settings, tasks, priority order, and local activity.
- **Task** — a global work item with region, team label, workstream, type, status, dates, progress, and tags.
- **Priority order** — the capped ordered list of active, non-archived task IDs.
- **Activity** — convenient local change history; it is not tamper-evident audit evidence.
- **Fictional sample** — intentionally invented data that is not derived from a private organization or person.
- **Public payload** — files and Git history proposed for the public repository.
- **Validation** — repeatable source, unit, workflow, privacy, and browser checks bound to a specific source state.
